# Security Policy

## Reporting a vulnerability

Please report security issues to pablorottendev@gmail.com.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/pablorotten/tmdb-sdk/issues

## Scope

This policy applies to the TMDB SDK packages maintained and published from
this repository.

This is an unofficial SDK for the TMDB public API, generated by
Pablo Antonio Rodriguez Rubio. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
